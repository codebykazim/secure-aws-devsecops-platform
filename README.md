# Secure End-to-End DevOps Platform on AWS

## Project Overview
This project demonstrates a comprehensive, secure, and automated DevOps lifecycle. It is designed to match real-world DevOps Engineer job requirements, encompassing Infrastructure as Code, Configuration Management, CI/CD, Containerization, Kubernetes Orchestration, Security Scanning, and Monitoring.

## Architecture
See [Architecture Overview](docs/architecture.md)

## Tools & Technologies
- **Cloud & IaC:** AWS, Terraform
- **OS & Automation:** Ubuntu Linux, Ansible
- **CI/CD:** Jenkins, SonarCloud
- **Containerization:** Docker, JFrog / Docker Hub
- **Orchestration:** AWS EKS (Kubernetes)
- **Monitoring & Alerts:** Prometheus, Grafana, Alertmanager
- **Security:** Trivy, UFW/iptables, Fail2ban
