# Job Description Mapping

This project is built to satisfy common requirements found in DevOps Engineer job descriptions.

| Job Requirement | Project Implementation |
| :--- | :--- |
| **Linux Administration** | EC2 setup, user management, package management, system monitoring commands. |
| **Infrastructure as Code** | Provisioning AWS VPC, EC2, and EKS using Terraform. |
| **Configuration Management**| Automating software installation and hardening with Ansible roles. |
| **CI/CD Pipelines** | Jenkins multi-stage pipeline triggered by GitHub webhooks. |
| **Containerization** | Dockerizing a Node.js application, optimizing image size and layers. |
| **Container Orchestration** | Deploying the app on AWS EKS with replicas, probes, and resource limits. |
| **Security & DevSecOps** | SonarCloud for code quality, Trivy for image vulnerabilities, Linux hardening. |
| **Monitoring & Observability**| Prometheus & Grafana stack, Alertmanager for SMTP alerts. |
| **Networking & Firewalls** | AWS Security Groups, UFW/iptables, Route 53 (if domain available). |
| **Incident Response** | Simulated deployment failure, troubleshooting via kubectl, Root Cause Analysis (RCA). |
